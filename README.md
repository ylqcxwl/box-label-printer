# 外箱标签打印程序

根据选择的产品信息，调用对应的 BarTender 打印模板打印外箱标签。

- **程序打包名称**：标签打印（`标签打印.exe`）
- **作者**：ylqc
- **运行环境**：Windows 7 及以上（32/64 位均可）；BarTender 10.0 及以上
- **特性**：纯绿色免安装、完全离线运行（可选联网检查更新/备份）、启动快、无后台进程、绝不修改打印模板

## 功能一览

| 模块 | 说明 |
|------|------|
| 打印标签 | SN 前缀/69码搜索选产品（**输入即筛选**，**选中行实心蓝高亮**）→ 扫码录入 → 满箱自动打印；不满箱可手动打印（空值补齐，数量按实际）；SN 前缀/规则/批次自动校验，已打印 SN 禁止重复录入；**更换产品会自动清空当前未打印的 SN，并把生产日期复位为当天**；产品详情末项显示**重量** |
| 打印记录 | 按 SN/箱号/日期范围查询（支持跨年，**无查询按钮：回车或停笔 0.3 秒自动刷新**）；筛选一键重置；**按住 Shift 点勾选框可一次选一整段**、已勾选行整行浅蓝底；批量导出 Excel（中文表头、列宽自适应）；按箱重打印；删除需密码；**列宽固定不随结果跳动** |
| 产品管理 | 产品录入/编辑/删除（双击行可直接编辑、**选中行实心蓝高亮**）；**模板只填文件名即可（不用写 .btw 后缀）**；Excel 批量导入导出（中文表头）；SN 前缀唯一 |
| 箱号规则 | 占位符拼装（年月日/当月流水/返修流水/工厂代码/SN前缀），每产品每月每批次独立计数、每月清零，打印成功才跳号；**删掉末尾的箱号后重新打印会复用该箱号**；**流水号可选 纯数字 / 字母 / 数字+字母 / 16 进制 / 自定义序列**，对话框内**实时预览** |
| SN 规则 | 占位符拼装 + 总位数控件，打印时校验；批次 `{BATCH}` 与**年月日占位符**均为「可选添加」，写了才按打印页所选日期/批次校验；流水号同样支持五种字符集 |
| 字段映射 | 产品字段与模板数据源名自由增删改；「箱号」为打印类字段，由程序在打印时自动填入 |
| 列表设置 | **统管程序内所有列表**：产品管理表格、打印页产品列表、新建产品弹窗字段顺序、打印记录表格的列顺序与显隐 |
| 系统设置 | 默认打印机（留空即跟随电脑默认打印机，输入框直接显示当前使用的那台）、模板文件夹（默认程序根目录下的 `templates`）、工厂代码、删除密码、自动/手动备份（保留最新 3 份）、GitHub 更新检查 |

> 软件图标：**连点侧边栏左上角 LOGO 10 次**即可更换（自定义图标存于 `data/custom_logo.png`）。

## BarTender 模板要求

- 模板（.btw）中的数据源必须是「命名数据源 / 命名字符串」，名称与软件「设置 → 字段映射」中的数据源名一致；
- 默认数据源名：`mingcheng`(名称) `guige`(规格) `xinghao`(型号) `yanse`(颜色) `SN4`(SN前缀) `SKU` `code69`(69码) `xianghao`(箱号) `shuliang`(数量) `zhongliang`(重量)；
- SN 数据源名为数字 `1、2、3、4、5……`（数量由产品整箱数与模板决定）；
- 软件打印时只在内存中赋值、以「不保存更改」关闭模板，**绝不修改模板任何样式及数据**。

## GitHub 仓库创建与一键打包流程

### 1. 创建仓库

```bash
cd 外箱标签打印程序
git init
git add .
git commit -m "feat: 外箱标签打印程序 v1.0.0"
git branch -M main
git remote add origin https://github.com/<你的用户名>/label-printer.git
git push -u origin main
```

（或在 github.com 网页上 **New repository** 建库后按提示推送。）

### 2. 一键打包（仅手动触发，提交代码不会触发工作流）

1. 打开仓库 → **Actions** → 左侧选择 **「打包标签打印程序」**；
2. 点击右侧 **Run workflow**；
3. 「版本号」输入框：
   - 填 `1.0.3` 之类 → 按指定版本打包；
   - **留空** → 自动在 `version.txt` 基础上迭代修订号（如 1.0.0 → 1.0.1）；
4. 点击绿色 **Run workflow** 按钮开始打包（Windows Server 2022 环境）；
5. 运行完成后，进入该次运行页面 → 底部 **Artifacts** 下载
   `标签打印_vX.X.X.zip`，解压后双击 `标签打印.exe` 即可使用；
6. 工作流结束会自动：
   - 把新版本号回写到仓库（`version.txt`、`app/version.py`、exe 文件属性）；
   - **清理本工作流的历史运行记录，只保留最新 2 条**。

### 3. 本地打包（可选）

需要本机安装 Python 3.8.10 (32 位)：

```bat
build.bat
```

产物在 `dist\标签打印\` 目录。

## 软件更新（可选功能）

在「设置 → 系统设置 → 更新设置」中填写仓库地址（`owner/repo`）并勾选
「启动时自动检查更新」；检测到新版本时主页左下角版本号旁出现红点，
到设置页点击「下载更新」获取更新包，解压后替换程序目录内同名文件即可
（`data` 数据目录不受影响）。留空仓库地址则完全离线。
